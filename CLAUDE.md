# Working on this project

- **Comments:** `.rs` files have `//!` file summaries only, no `///` or `//`. The `.ron` files keep their field-reference header comments.
- **"Add changes"** means update CHANGELOG.md and README.md, then commit and push to `main`.
- **TODO.md** is a shared list, reviewed with the user. Jot down anything noticed while working (bugs, QoL, ideas) as it comes up, keep its open questions current, and add a line to its review log after each stage or planning discussion. Raise open questions with the user rather than settling them silently.
